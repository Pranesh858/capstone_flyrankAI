# capstone_flyrankAI

FlyRank AI internship capstone. This repo is the public workspace for AI-assisted development: toolchain, conventions, and the portfolio artifact that follows.

## Status

Setup phase. Toolchain is in place (Node.js LTS, Git, Cursor). Product code comes next.

## Stack

- Runtime: Node.js LTS
- VCS: Git + GitHub
- Editor / AI: Cursor
- Language: TypeScript (with Python available for later backend/AI work)
- Commits: [Conventional Commits](https://www.conventionalcommits.org/)

## Setup

```bash
git clone https://github.com/Pranesh858/capstone_flyrankAI.git
cd capstone_flyrankAI
node --version
git --version
```
